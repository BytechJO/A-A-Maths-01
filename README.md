# A&A Maths 01

React web version of A&A Maths 1. Includes the intro, contents page, and all 13 activities in Unit 1A (Let’s Count!). Other units are displayed but disabled. No Flash runtime is required.

## Run locally

Requires Node.js 22.12+ and npm.

```sh
npm ci
npm run dev
```

Open http://127.0.0.1:5173/.

## Build

```sh
npm run build
npm run preview
```

Deploy the `dist` directory to a static web host.

## Tests

```sh
npm test
```
